Random Cats
A simple web page that lets you browse cat photos and breed facts. It uses The Cat API to fetch images and breed information.
Features

Pick a breed: Sphynx, Bengal, or Abyssinian
Switch between two views:

Cat Photos – a grid of 9 images plus a short breed description
Breed Facts – origin, temperament, and life span

Files

home.html – page structure and navigation
home.css – styling
home.js – fetches data from The Cat API and updates the page

How to Run

Keep all three files in the same folder.
Open home.html in a web browser.
